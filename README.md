# KairGrisha — Portfolio

A simple, single-page portfolio website (plain HTML + CSS, no build step).

- X / Twitter: [@KairGrisha](https://x.com/KairGrisha)
- Project: [duel-club.com](https://duel-club.com/)

## Run locally

Open `index.html` in a browser.

## Deploy (GitHub Pages)

Settings → Pages → Source: **Deploy from a branch** → `main` / `(root)` → Save.
The site will be live at `https://<username>.github.io/kairgrisha-portfolio/`.

## Customize

- **Token CA:** shown in the Duel Club card (`#ca-text` in `index.html`).
- Edit `index.html`: replace the placeholder text in **About** and **What I Do**.
